# Что это?

Приложение для телефона: фотографируешь что угодно, тыкаешь в предмет и получаешь справку двух видов.
- **Что это?** Как называется, для чего нужно, как устроено, когда появилось.
- **История.** Кто и когда создал, чем знаменито, культурный контекст.

Каждый ответ состоит из двух частей: короткая справка для взрослого и пересказ простыми словами для ребёнка. Ответ можно прослушать вслух.

## Как устроено

```
Телефон (веб-приложение, папка docs/)
   │  фото + место касания
   ▼
Функция в Yandex Cloud (папка function/)   ← здесь хранится ключ GigaChat
   │
   ▼
GigaChat API (Сбер)
```

- `docs/` — само приложение (HTML/JS), публикуется на GitHub Pages.
- `function/index.py` — посредник: получает фото, отправляет его в GigaChat и возвращает ответ.
- `function/certs/` — корневой сертификат НУЦ Минцифры (без него сервер GigaChat не открывается).
- `dev_server.py` — запуск на компьютере для проверки.
- `.env` — ключи для локального запуска. Этот файл **не попадает в git**.

## Шаг 1. Серверная часть в Yandex Cloud (~15 минут)

1. Зайди в [консоль Yandex Cloud](https://console.yandex.cloud) и привяжи платёжный аккаунт. Это нужно даже для бесплатного объёма.
2. Открой **Cloud Functions** → **Создать функцию** и назови её, например, `chto-eto`.
3. В редакторе функции:
   - **Среда выполнения:** Python 3.12 (или новее);
   - **Способ:** ZIP-архив → загрузи `function.zip` из корня проекта (его собирает команда ниже);
   - **Точка входа:** `index.handler`;
   - **Таймаут:** `60` секунд (по умолчанию 3–5 секунд, а этого мало: GigaChat отвечает 10–30 секунд);
   - **Память:** 256 МБ;
   - **Переменные окружения:**
     - `GIGACHAT_AUTH_KEY` — «Ключ авторизации» из кабинета GigaChat API;
     - `APP_SECRET` — придумай пароль (например, 3–4 случайных слова). Его же потом введёшь в телефоне.
   - Нажми **Сохранить изменения**.
4. На странице функции включи переключатель **Публичная функция**. Это не опасно: без пароля `APP_SECRET` функция ничего не делает.
5. Скопируй **Ссылку для вызова** (вида `https://functions.yandexcloud.net/d4e…`).

Как собрать `function.zip` (в папке проекта):

```powershell
python make_zip.py
```

## Шаг 2. Приложение на GitHub Pages (~10 минут)

1. Создай на [github.com](https://github.com/new) репозиторий `chto-eto`. Он может быть публичным: в нём нет ключей.
2. Отправь туда код (PowerShell, в папке проекта):

```powershell
git add -A
git commit -m "Первая версия"
git remote add origin https://github.com/<твой-логин>/chto-eto.git
git push -u origin main
```

3. В репозитории открой **Settings → Pages → Build and deployment**: Source = *Deploy from a branch*, Branch = `main`, папка = `/docs` → **Save**.
4. Через 1–2 минуты приложение будет доступно по адресу `https://<твой-логин>.github.io/chto-eto/`.

## Шаг 3. Установка на телефон (Samsung Galaxy S24)

1. Открой ссылку из шага 2 в **Chrome**.
2. Нажми **⋮ → «Добавить на главный экран» → «Установить»**. На рабочем столе появится иконка с лупой, и приложение будет открываться на весь экран.
   (В Samsung Internet это тоже работает: **≡ → «Добавить страницу на» → «Главный экран»**.)
3. Открой приложение → ⚙️ **Настройки**:
   - **Адрес сервера:** ссылка из шага 1;
   - **Пароль приложения:** твой `APP_SECRET`;
   - **Возраст ребёнка** и (по желанию) **город**.
4. Нажми **Проверить связь**. Если появилось «✅ Связь есть», нажми **Сохранить**.

## Как пользоваться

- **📷 Сфотографировать** открывает обычную камеру Samsung, поэтому оптический зум работает (порт через залив, верх собора, картина под потолком).
- После снимка ткни в нужный предмет: появится красный кружок. Потом нажми **Что это?** или **История**.
- В музее захватывай в кадр **табличку** рядом с экспонатом: модель прочитает её, и ответ будет точнее.
- **🧸 Только для ребёнка** читает вслух только детскую часть ответа.
- 🕘 — история прошлых ответов (хранится только на телефоне).

## Важно знать

- Модель может ошибаться, особенно с малоизвестными памятниками и датами. Ей прописано честно говорить «не уверена», но непроверенные факты лучше уточнять.
- По умолчанию используется `GigaChat-3-Ultra`. Модель меняется переменной `GIGACHAT_MODEL` в настройках функции (подходят также `GigaChat-2-Max` и `GigaChat-3-Pro`).
- Бесплатный объём для физлиц — несколько десятков миллионов токенов в год на модель. Один запрос с фото — это несколько тысяч токенов, так что для семейного использования должно хватить с большим запасом. Остаток видно в кабинете GigaChat API.
- Если ключ GigaChat куда-то утёк, нажми «Получить ключ» ещё раз в кабинете и замени `GIGACHAT_AUTH_KEY` в функции.

## Локальная проверка на компьютере

Создай файл `.env`:

```
GIGACHAT_AUTH_KEY=<ключ авторизации>
APP_SECRET=local-dev-secret
```

Потом запусти сервер и открой `http://localhost:8000`. В настройках укажи адрес `http://localhost:8000/api` и пароль `local-dev-secret`.

```powershell
python dev_server.py
```

После изменения файлов в `docs/` увеличь номер версии `CACHE` в `docs/sw.js`, иначе телефон может показывать старую версию.
